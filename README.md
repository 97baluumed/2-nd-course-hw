Проект выполнен в рамках обучения в SkyPro. 

Описание проекта: 
Одностраничный сайт для развлекательных целей (сайт с мини-играми).

Сроки выполнения: 
Проект был выполнен за две недели. 
- Три дня — на разработку структуры и дизайна.
- Семь дней — на вёрстку и интеграцию элементов.
- Четыре дня — на тестирование и доработку.

Особенности проекта: 
- Адаптивность. Сайт корректно отображается на мобильных устройствах, планшетах и компьютерах.
- Интерактивные элементы. Реализована анимация при прокрутке и плавные переходы.

Использованные технологии: 
-HTML5, CSS3 (Flexbox, Grid); 
-JavaScript; -Bootstrap 5; 
-Git и GitHub для контроля версий;
